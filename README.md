Este repositório reúne resoluções de exercícios, algoritmos e projetos práticos desenvolvidos na linguagem **Prolog**. O foco principal é a transição do pensamento imperativo/orientado a objetos para o **paradigma declarativo**, explorando conceitos de unificação, regras recursivas, *backtracking* e estruturas de listas.

---

## 📌 Módulos & Tópicos Implementados

| Módulo | Conceitos Abordados |
| :--- | :--- |
| **`01_Fundamentos`** | Fatos, regras simples, relações de parentesco, consultas no terminal e variáveis lógicas. |
| **`02_Recursao`** | Regras recursivas, caso base vs. caso recursivo, cálculo de fatorial e sequência de Fibonacci. |
| **`03_Listas`** | Manipulação do operador Cabeça/Cauda `[H\|T]`, verificação de pertencimento (`membro/2`), concatenação e inversão. |
| **`04_Controle_e_Corte`** | Utilização do operador de corte (*Cut* `!`), negação por falha (`\+`) e otimização de busca. |
